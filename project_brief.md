# Project Brief: Recipe Assistant Agent

## Name
recipe-assistant

## Description
A personal chef and recipe assistant ("Chef Gemini") that suggests meals based on available ingredients and manages a list of persistent favorite recipes.

## Archetype & Core Actions
A conversational culinary agent that helps users discover recipes using on-hand ingredients and save their favorite dishes.

## Tools
- `save_favorite_recipe`
- `list_favorite_recipes`
- `get_favorite_recipe`
- `delete_favorite_recipe`
